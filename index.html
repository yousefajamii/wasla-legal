Wasla

Wasla is a mobile job application assistant that helps users find suitable jobs and send applications by email.

How it works

Users create a profile, choose their job preferences, connect their own Gmail account, and select job opportunities. Wasla sends the user's cover letter and resume only to the selected employer.

Gmail access

Wasla uses Gmail only to send job application emails on behalf of the user. It does not read, search, delete, or modify emails and does not access contacts.
